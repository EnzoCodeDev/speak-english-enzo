# Frases para entrevistas de programación

Revisión del temario: **9 de noviembre de 2026**.

Las tandas 6–10 contienen **250 frases originales de práctica**, no una transcripción de
entrevistas, preguntas filtradas ni una clasificación de las más frecuentes. Combinan
preguntas de entrevistador, preguntas del candidato y ejemplos de respuestas cortas.
Las respuestas se adaptan a la experiencia real de cada persona: no deben memorizarse
para atribuirse proyectos, competencias o resultados que no se tienen.

## Organización

| Tanda | Frases | Tema |
|---|---:|---|
| 6 · Perfil | 50 | Presentación, experiencia, motivación, aprendizaje y objetivos |
| 7 · Equipo | 50 | Proyectos, colaboración, feedback, decisiones y responsabilidad |
| 8 · Código | 50 | Requisitos, algoritmos, complejidad y explicación durante live coding |
| 9 · Web | 50 | JavaScript, TypeScript, React, accesibilidad, APIs y PostgreSQL |
| 10 · Sistemas | 50 | Diseño, calidad, producción, IA responsable y preguntas al equipo |

El lenguaje busca ser breve y practicable en voz alta; el vocabulario técnico no está
limitado a las 200 palabras del bloque de VRChat. Cada palabra tiene una entrada de
diccionario con significado y pronunciación aproximada para hispanohablantes.
La transcripción aproximada es una ayuda inicial, no sustituye el audio ni es IPA.

## Fuentes primarias consultadas

- **Microsoft Careers — Technical interviewing**
  https://careers.microsoft.com/v2/global/en/hiring-tips/technical-interviewing
  Su guía destaca aclarar ambigüedades, planear antes de programar, explicar las decisiones,
  probar soluciones y discutir algoritmos, estructuras de datos y diseño de sistemas.
  Es la base temática de los bloques de código y calidad, no la fuente literal de las frases.
- **Atlassian — Engineering interview handbook**
  https://www.atlassian.com/company/careers/resources/interviewing/engineering
  Describe evaluación de resolución de problemas, diseño de código, estructuras de datos,
  diseño de sistemas y conversación sobre experiencia y objetivos. Da importancia a comunicar
  alternativas y restricciones como fiabilidad y coste. Orienta los bloques de equipo y sistemas.
- **Amazon Jobs — Software development interview topics**
  https://amazon.jobs/content/en/how-we-hire/interview-prep/software-development-topics
  Recomienda confirmar con selección qué habilidades se evaluarán. Su temario incluye código,
  algoritmos, estructuras de datos, diseño, bases de datos y sistemas distribuidos, entre otros.
  Sirve de referencia para la cobertura técnica, no demuestra la frecuencia de ninguna frase.

## Límites de la práctica

- El proceso varía por empresa, nivel y puesto. El temario de una vacante y las indicaciones
  del reclutador tienen prioridad; estas tandas no prometen cubrir todas las entrevistas.
- El bloque web es una selección editorial para perfiles frontend y full stack, no una
  afirmación de que todas las empresas entrevisten sobre React o PostgreSQL.
- Las frases sobre IA enseñan a explicar el propio criterio, revisar resultados y proteger
  datos. **Pide permiso antes de usar herramientas durante una entrevista**: incluirlas aquí
  no significa que una empresa las permita ni que estén presentes en todos los procesos.
- Practicar pronunciación no equivale a dominar las respuestas técnicas ni garantiza empleo.
